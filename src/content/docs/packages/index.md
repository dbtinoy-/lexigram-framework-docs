title: Packages
description: "Overview of all Lexigram packages organized by category"
---

Lexigram consists of 40+ packages organized into categories. Each extension package depends only on `lexigram-contracts` and the core `lexigram` package.

```
lexigram-contracts   →   Zero dependencies (protocols, types, domain, Result)
lexigram             →   Core framework (container, DI, registry, logging, config)
lexigram-*           →   Extension packages
```
